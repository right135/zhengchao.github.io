科研成果

UMAO: Coupling Cache Lifecycle and Admission for Agents on Unified Memory （投稿至 ICLR'27） 面向 GB10 统一内存的多轮 Agent，协同缓存生命周期与请求准入，以连续前缀协调卸载、恢复与重计算；
实现 87.5%-90.3% 前缀复用，平均/P99 TTFT 最高加速 2.1×/6.4×。
APEX: Append-Aware P/D-Disaggregated Scheduling for Efficient Agent Serving （投稿至 ATC'27） 针对 P/D 解耦中 Decode 引发的 KVCache 同步滞后，提出 TPOT-Aware Append 请求调度；
结合跨轮上下文状态协调 Prefill/Decode，提升多轮 Agent 服务效率。
PACK: A Kernel Agent for Coordinated Kernel Generation Across Shapes （投稿至 DAC'27） 以硬件区域引导跨 Shape Kernel 搜索，并按部署预算选择互补实现、反馈优化弱势 Shape；
A800 九类算子几何平均加速 1.59×，六类算子排名第一。
Artemis: Document-oriented KVCache Reuse for Efficient Retrieval-Augmented Generation Serving （投稿至 ATC'27） 提出面向文档的 KVCache 复用机制，在检索结果动态组合下识别并复用已有文档缓存；
减少重复上下文预填充，降低 RAG Serving 推理开销。
RAGPulse: A Real-World RAG Workload Capturing Authentic Temporal Reuse Patterns for Efficient Serving （EMNLP'26） 构建真实 RAG 工作负载，系统刻画请求到达、文档热度与时间复用规律；
为 KVCache 策略、请求调度和 RAG 服务系统评测提供数据支撑。
